# Security Policy

## Reporting Security Vulnerabilities

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, please use one of the following channels:

1. **GitHub Private Vulnerability Reporting (Preferred):**
   Navigate to the affected repository's **Security** tab, select **Report a vulnerability**, and submit your report privately through GitHub's advisory pipeline.

2. **Email (Alternative):**
   Send details directly to `105177734+yegear1@users.noreply.github.com`.

### What to Include in a Report

- Detailed description of the vulnerability.
- Steps or proof-of-concept (PoC) to reproduce the issue.
- Potential impact and affected versions or environments.

We will acknowledge receipt within 48 hours and work with you to triage and address the issue responsibly before any public disclosure.
