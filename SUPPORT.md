# Support Guidelines

Looking for help with a project maintained by [@yegear1](https://github.com/yegear1)? Please follow the steps below before opening an issue.

## 1. Documentation & README

Before requesting support, review the repository's documentation:
- **`README.md` / `README.pt-br.md`**: Installation instructions, quickstart steps, configuration variables, and CLI/API usage examples.
- **Existing Issues**: Search both open and closed issues in the repository to see if your question or problem has already been resolved.

## 2. Where to Ask Questions

Please **do not** open bug report issues for general usage questions, configuration help, or environment troubleshooting.

- **Usage Questions & Ideas:** If the repository has **GitHub Discussions** enabled, open a thread in the **Q&A** or **General** category.
- **Verifiable Bugs:** If you have confirmed a reproducible defect in the codebase, open an issue using the [Bug Report form](./.github/ISSUE_TEMPLATE/bug_report.yml) with complete reproduction steps and environment details.
- **Feature Proposals:** If you want to propose a new capability, use the [Feature Request form](./.github/ISSUE_TEMPLATE/feature_request.yml).
- **Security Vulnerabilities:** Do not report security issues publicly. Follow our [Security Policy](./SECURITY.md) for private disclosure.
